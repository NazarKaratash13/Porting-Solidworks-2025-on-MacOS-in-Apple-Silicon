# SOLIDWORKS V3. Меню macOS и Toolbox

25 ноября 2026 г. Проверка на установленной `~/Applications/SOLIDWORKS 2025 V3.app` с отдельной копией детали. Исходный коммит `621834a`.

| Проверка | Результат |
|---|---|
| Штатный «Сохранить как» | **PASS для вызова.** Прослежена команда MFC `WM_COMMAND 0xe104`. После обновления `RunCommand(620)` этой же команды открыл AppKit `NSSavePanel` с идентификатором `save-panel`. |
| Запись через новую точку входа | **НЕ ПРОВЕРЕНО.** В автоматизации кнопка Save осталась недоступной после подстановки имени через Accessibility. Диалог закрыт без записи. Запись детали и сборки через уже существовавшую панель проверена в предыдущем прогоне. |
| Строка меню macOS | **PASS для меню.** Видны «Файл», «Правка», «Вид», «Вставка», «Инструменты», «Окно» и «Справка». В меню добавлены основные команды из библиотеки типов SOLIDWORKS 2025 SP05. Контекстные пункты и надстройки доступны в исходном меню внутри окна. |
| Путь Toolbox | **PASS.** База `swbrowser.sldedb` размером 20 250 624 Б побайтно совпала с копией в составе установки. Путь `SOLIDWORKS Data` заменён на `C:\SOLIDWORKS Data` в префиксе V3. После этого V3 открыла тестовую деталь через Finder. Настройка сохранилась в реестре. API вернул 15, 17 и 13 стандартов для простого отверстия, цековки и зенковки соответственно. |
| Finder и один экземпляр | **PASS.** `.sldprt`, `.sldasm` и `.slddrw` назначены V3. После перезапуска наблюдался один `SLDWORKS.exe`. |
| Task Pane | **НЕ ПРОВЕРЕНО.** Wine запрашивает перерисовку полосы, пройденной заголовком, после выхода из Win32 resize. Повторная попытка получить окно после ввода завершилась ошибкой ScreenCaptureKit. При узкой панели подпись по-прежнему теснит кнопки заголовка. |
| Галочка и крестик | **ГАЛОЧКА FAIL в предыдущей проверке.** Обычный клик не завершил инструмент «Окружность», диагностический `BM_CLICK` его завершил. Крестик в предыдущем прогоне открыл подтверждение отмены. Исправление ввода пока отсутствует. |
| Шрифты | **НЕТ ВОСПРОИЗВЕДЕНИЯ.** На новом снимке предупреждение о Toolbox. В префиксе обнаружены записи и файлы Arial, Tahoma, Arial Unicode MS и Century Gothic. Имена отсутствующих шрифтов для проблемного документа неизвестны. |

Панель «Сохранить как» поддерживает родные форматы детали, сборки и чертежа.
Для исходного диалога SOLIDWORKS с форматами экспорта предусмотрен вызов
«Сохранить как» из меню внутри окна с удерживаемой клавишей Shift.

Для применения настройки Toolbox в другом экземпляре V3 со штатной базой
в `C:\SOLIDWORKS Data\lang\english` выполните в его префиксе при закрытом
SOLIDWORKS.

```bat
reg.exe add "HKCU\Software\SolidWorks\SOLIDWORKS 2025\General" /v "Toolbox Data Location" /t REG_SZ /d "C:\SOLIDWORKS Data" /f
```

Оба обновлённых модуля Mach-O прошли проверку подписи и сравнение экспортов.
Контрольная сумма OpenGL совпала. `python3 tools/dev.py check` завершился
успешно, 57 тестов, один пропущен.

Закрытая старая сборка перенесена на том же томе в
`~/Library/Application Support/SOLIDWORKS 2025/Archive/SOLIDWORKS 2025.app.backup`.
Перенос сохранил inode и содержимое. В `~/Applications` и `/Applications`
осталась одна сборка SOLIDWORKS с расширением `.app`.

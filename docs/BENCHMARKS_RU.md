# Замеры SOLIDWORKS V3 на Mac с M4

| Параметр | Значение |
| --- | --- |
| Mac | Apple M4, 16 ГиБ |
| Система | macOS 27.2.1, сборка 26B131 |
| SOLIDWORKS | 2025 SP05 Student Edition |
| Среда | установленные V3, CrossOver 26.3.0 и Rosetta |
| Модели | простая деталь и тестовая сборка с компонентами Toolbox |

## Результаты

Время от команды открытия `.app` до момента, когда API SOLIDWORKS сообщал об активной тестовой сборке, составило **28,333 / 27,424 / 27,305 с**. Медиана — **27,424 с**. Между запусками SOLIDWORKS и его процесс Wine штатно завершались. Системные кэши сохранялись. [Данные трёх запусков](benchmarks/startup.json).

| Операция | Деталь, медиана | Сборка, медиана |
| --- | ---: | ---: |
| Открытие | 2,480 с | 3,607 с |
| Перестроение | 0,359 с | 0,464 с |
| Сохранение копии | 0,223 с | 0,233 с |

По пять проходов на каждый тип файла, чередуя деталь и сборку. Операции синхронно вызваны через COM. Через секунду после сохранения снята сумма `phys_footprint` двух процессов с помощью macOS `footprint`. Сумма выросла с **2,60 ГиБ** при двух открытых документах до **4,52 ГиБ** при одиннадцати. Исходные файлы оставались открытыми, поэтому времена открытия и расход памяти зависят от положения в серии. [Сырые времена в миллисекундах и память в байтах](benchmarks/operations.csv).

Эти цифры описывают один Mac и лёгкие тестовые модели. Для оценки масштабирования нужны отдельные прогоны с фиксированным количеством открытых документов, крупными сборками и замером частоты кадров.

## Воспроизведение

Нужны установленная V3, её Wine-профиль, Python 3.11+, MinGW-w64 и собственные тестовые документы. Сборка должна находить свои компоненты после копирования. Сначала сохраните открытые в SOLIDWORKS документы. При `--restarts 3` скрипт трижды штатно перезапускает приложение. Уберите этот параметр для замера операций в уже открытом приложении.

```sh
mkdir -p build
python3 tools/solidworks-bench/run.py \
  --app "/Applications/SOLIDWORKS 2025.app" \
  --prefix "$HOME/Library/Application Support/org.swv3.desktop/prefix" \
  --part "/path/to/fixture.SLDPRT" \
  --assembly "/path/to/fixture.SLDASM" \
  --output "./build/benchmark-m4" \
  --restarts 3 --operations 5
```

Каталог `--output` должен быть новым. Скрипт создаёт в нём копии документов, COM-утилиту и CSV. Состояние продукта и лицензию подготавливает пользователь. В видео проверка вставки третьего болта — отдельный проход, независимо от серии замеров.

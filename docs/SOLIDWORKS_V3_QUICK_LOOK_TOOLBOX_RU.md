# Quick Look и библиотека Toolbox в SOLIDWORKS 2025 V3

## Quick Look

В существующий пакет V3 добавлены два расширения Quick Look для macOS на Apple Silicon. Finder показывает миниатюры и открывает предварительный просмотр пробелом для `.SLDPRT`, `.SLDASM` и `.SLDDRW`. Расширения работают с файлами по всему Finder и читают сохранённое изображение локально. Обработчики открытия документов по-прежнему указывают на V3.

Поддерживаются сжатые PNG из современных файлов и целые PNG в старых контейнерах CFB. Для повреждённых, пустых и неподдерживаемых превью Finder использует штатный вид файла. В том числе «Контроль записи.SLDPRT» содержит белое изображение, хотя в документе есть геометрия. Встроенная картинка зависит от того, какой вид записал SOLIDWORKS при сохранении.

Сборка из корня проекта

```sh
bash tools/solidworks-quicklook/build.sh /path/to/output
```

Для установки оба подписанных `.appex` из каталога сборки помещаются в `Contents/PlugIns` существующего пакета V3 и регистрируются через `pluginkit -a`. Исходники и инструкции по формату контейнера находятся в [tools/solidworks-quicklook](../tools/solidworks-quicklook). Используются [расширения Quick Look UI](https://developer.apple.com/documentation/quicklookui) и [Quick Look Thumbnailing](https://developer.apple.com/documentation/quicklookthumbnailing/providing-thumbnails-of-your-custom-file-types).

На macOS 27.2.1 arm64 в Finder визуально проверено окно Quick Look детали «Проверка детали». Системный API `QLThumbnailGenerator` вернул миниатюры 512 × 384 для детали, сборки `plug-5pindin-asm.sldasm` и чертежа `db9 male-hblock.slddrw`. Парсер вернул отсутствие изображения для файла с расширением TXT, слишком короткого файла, обрезанного потока DEFLATE, произвольных данных и детали с белой картинкой. Команда `python3 tools/dev.py check` завершилась успешно. Она выполнила 57 тестов, один из них пропущен.

## Toolbox

В `C:\SOLIDWORKS Data` существовали целая база `lang\english\swbrowser.sldedb` и индекс с пустым деревом, хотя база помечала стандарты установленными. Подпапки `browser` с моделями отсутствовали. Из локальных архивов официального комплекта SOLIDWORKS 2025 SP05 восстановлены 1844 модели в 19 папках. Модели размещены внутри существующего пакета V3 и занимают около 434 МиБ. Пустой индекс сохранён в резервной копии. После нажатия «Добавить сейчас» SOLIDWORKS создал новый индекс размером 653 КиБ и показал в библиотеке ISO, DIN, Ansi Inch, Ansi Metric и другие стандарты. ISO открывается и показывает категории крепежа. Вставка крепежа в сборку отдельно не проверялась.

## Вкладки Task Pane

До правки окно модели `swMdiClient` заканчивалось на x=2942 и перекрывало всю полосу вкладок x=2888–2942. Поэтому подсказки появлялись над областью, где пользователь не видел значков. Правка Win32u ограничивает ширину MDI только при фактическом нахлёсте на видимую полосу закреплённой панели. После перезапуска на той же детали правый край MDI оказался на x=2888, значки библиотеки, палитры видов, оформления и пользовательских свойств стали видимы.

Вкладки видны и при узкой библиотеке без открытого документа. После перетаскивания разделителя на 242 пикселя влево полоса переместилась вместе с панелью. При повторном открытии детали правый край MDI и левый край вкладок совпали на x=2850. В узкой панели длинная подпись местами касается кнопок в заголовке. Бинарный модуль OpenGL совпадает по SHA-256 с исходным.

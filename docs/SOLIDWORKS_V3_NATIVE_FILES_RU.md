# Файлы macOS в SOLIDWORKS 2025 V3

24–25 ноября 2026 г., Apple M4 и macOS 27.2.1. Локальная V3 находится в
`~/Applications/SOLIDWORKS 2025 V3.app`. Используется прежний runtime
и префикс этого пакета. Замены модулей выполнены при штатно закрытом
SOLIDWORKS. OpenGL и рабочий пакет в `/Applications` не менялись.

Верхнее меню macOS «Файлы Mac» содержит «Открыть на Mac…» (`⌘O`) и
«Сохранить как на Mac…» (`⌘⇧S`). AppKit передаёт выбранный локальный путь
в Wine как `Z:\Users\…`. Диск `Z:` отображает путь от корня macOS с
правами текущего процесса. Открытие и сохранение делегируются активному
SOLIDWORKS. При сохранении мост повторно сверяет тип, заголовок и путь
документа. Пакет объявляет три расширения и их типы, зарегистрированные на
этом Mac. Обработчик по умолчанию установлен средствами NSWorkspace.
[Документация Apple](https://developer.apple.com/documentation/appkit/nsworkspace/setdefaultapplication%28at%3Atoopen%3Acompletion%3A%29?changes=_7)

## Сборка

Патч нативных файлов применяется к исходникам Wine V3. Сборка
`winemac.so` включает изменённый `cocoa_app.o`. Мост собирается
компилятором MinGW как `C:\sw-v3\file-bridge.exe` внутри префикса.

```sh
x86_64-w64-mingw32-gcc -O2 -Wall -Wextra -Werror -municode \
  tools/solidworks-v3-file-bridge.c -o file-bridge.exe -lole32 -loleaut32 -luuid
swiftc -O -parse-as-library tools/set-solidworks-v3-defaults.swift \
  -o set-solidworks-v3-defaults
```

`tools/solidworks-v3-local-launcher.sh` передаёт PID основного процесса
Wine драйверу. Дочерние процессы не устанавливают меню V3.
Инструмент проверки ассоциаций принимает путь к пакету и `--check`.

В `Info.plist` для каждого расширения задаётся тип `Editor` и имя
родного формата. В `LSItemContentTypes` указывается в том числе
текущий системный тип для этого расширения. На проверенном Mac
это `com.shapr3d.solidworks.sldprt`, `com.shapr3d.solidworks.sldasm`
и `com.shapr3d.solidworks.slddrw`. Собственный тип V3 сохраняется
в `UTImportedTypeDeclarations`. После регистрации пакета инструмент
без `--check` устанавливает ассоциации пользователя.
